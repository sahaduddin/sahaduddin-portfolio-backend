# Portfolio Project

This project contains a full-stack portfolio with Angular frontend and Node.js backend.

## Setup Instructions

### Prerequisites
- Node.js & npm
- Angular CLI
- GitHub repository clone

### Backend Environment Setup
1. Copy `.env.example` to `.env` inside the `angular-portfolio-backend` folder.
2. Fill in your own values for SMTP, Gemini API, WhatsApp token, and database credentials.
3. Do not commit the `.env` file to GitHub.
